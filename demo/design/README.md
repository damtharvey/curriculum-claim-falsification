# Demo UI design

Six desktop artboards (1280×900) for the demo frontend and its configuration pages. Live canvas: https://claude.ai/artifact/Ugu5uMvtyZSJEuYPhvcKjN

Frontend states: `Main.dc.html` (item explorer), `Item-Witness.dc.html`, `Item-NoWitness.dc.html`.
Configuration templates: `Admin-Rules.dc.html`, `Admin-Claims.dc.html`, `Admin-Data.dc.html`.

Rule traces on the item pages are worked from the rule definitions in `rules/apriori.json`, not from a live run. Bracketed values (`[REGION]`, `[SIZE]`) are placeholders.
