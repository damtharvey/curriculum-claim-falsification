\section{Conclusion}
\label{sec:conclusion}

A tag on an assessment item is a claim about what passing requires, and that claim can be tested with executable counterexamples rather than with student data or expert judgment. We built one instance of an automated curriculum falsifier and ran it on one subject. The inputs it needs, the tag text, the item text, the keys, an executable scoring rule, and a restriction on the solver that a machine can enforce, are already public for large assessment programs, and where they are public the search runs.

We do not expect this instance to be deployed. We do expect searches like it to become part of assessment test suites. A discovered bypass is a regression test: a revised item must fail it and a competent reference solver must still pass, and the test can be run by item writers before release, by purchasers before adoption, and by researchers before a tagged item serves as an outcome measure. The same holds for any subject whose items and scoring rules can be executed, and it reaches constructed response as soon as a rubric has an executable scorer.
